# Music Player UI

A responsive, Spotify-inspired music player interface built with HTML, CSS, and JavaScript.

🔗 Live Demo: [diksha-pal04.github.io/music-player-ui](https://diksha-pal04.github.io/music-player-ui/)


## ✨ Features

- Sidebar navigation with Home and Search
- "Your Library" section with playlist and podcast prompts
- Scrollable content sections — Recently Played, Trending Now, Featured Charts
- Song cards with title, artist, and cover art
- Sticky bottom music player bar with:
  - Album art, song title, and artist
  - Playback controls (previous, rewind, play/pause, forward, next)
  - Progress/seek bar with current and total time
- Like/favorite icon on tracks and the now-playing bar
- Google Fonts (Montserrat) and Font Awesome icons

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- [Font Awesome](https://fontawesome.com/) — icons
- [Google Fonts](https://fonts.google.com/) — Montserrat
